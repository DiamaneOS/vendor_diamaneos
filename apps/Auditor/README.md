Prebuilt of the DiamaneOS Auditor (`de.diamaneos.auditor`), built from
[DiamaneOS/Auditor](https://github.com/DiamaneOS/Auditor).

`prebuilt/app-release.apk` is its release build, signed with the DiamaneOS Auditor key. The image
build keeps that signature.

Source revisions, artifact hashes and the APK certificate digest are recorded in [provenance.json](provenance.json).
